These fit the operator dashboard you already have (missions, memory, Calendar, Gmail, Croatian/English voice). They are not part of this build unless you pull one in.





Low-credit warning before voice. Voice is the expensive path (transcribe, then Thesys, then Rex). If OpenRouter or Thesys is under $1, say so before Start Voice Chat instead of failing mid-sentence.



Morning briefing on the board. get_briefing already lists overdue and due-today missions. Extend that card with today’s Google events, an unread Gmail count, and Zagreb weather from Open-Meteo (no API key). The footer still says LOCATION · LOCAL NODE; weather belongs there too.



Recurring missions. Spoken plans such as gym and the shop get recreated as one-off tasks. A weekly repeat would keep them on the board without asking again.



Due-soon alert while the tab is open. Focus mode already filters overdue and due today. A quiet in-tab notice when something crosses its due time is the missing piece. No host CPU monitor is required for that.



Evening close-out. One command: what finished today, what is still open, what moved to tomorrow.



Unread mail in the intelligence feed. Gmail is already connected; the feed currently only talks about missions.



Quiet hours for speech. Keep listening if you want, but do not play Rex after a set time.

Leave the sidebar entries for Agents, Knowledge Base, Tools & Skills, and Workflows as they are. They are already marked not live, and empty pages would not help the $8 budgets. A host CPU/RAM panel needs a local agent the browser does not have.
